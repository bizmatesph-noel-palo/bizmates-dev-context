# ASCH Pattern 3 — Case Data (from Kuroda-san's Excel)

**Source:** Kuroda-san's specification Excel v3
**Pattern:** 3 — Lesson started before campaign period, Coaching starts during campaign
**Scenario:** B2C new student, Loyal discount applies

## Key Characteristics

- Lesson (Daily 1) starts on 9/28 — BEFORE campaign period
- Coaching 30-min starts on 10/3 — during campaign period
- App starts with Coaching on 10/3
- First Month 50% applies to Coaching ONLY (not Lesson — Lesson was already active)
- Month-6 50% discount applies to both, but counted independently per product
- Lesson month-6 = counted from 9/28 start (6th charge = 2027/3/28 cycle)
- Coaching month-6 = counted from 10/3 start (6th charge = 2027/3/3 cycle)
- Loyal discount (5%) applies after Honki Set benefit period ends

## Implications for Design (differs from Pattern 1 and 2)

1. **Pre-campaign charges exist** — Lesson was active before Honki Set. The first Lesson charge in the proration group is NOT the first Lesson charge overall.
2. **First Month 50% applies to Coaching only** — Lesson doesn't get First Month because it was already active when Honki Set started.
3. **Month-6 counting is per-product** — Lesson counts from 9/28 (its start), Coaching counts from 10/3 (its start). Month-6 discount fires on different calendar dates.
4. **Non-aligned contract boundaries** — Lesson runs 28th-27th, Coaching runs 3rd-2nd. More complex than Pattern 2's 1st/15th split.
5. **Month-6 O changes** — When the 50% discount fires on the 6th charge, that charge gets a NEW O value (new proration group with discounted M). The O from prior months doesn't carry into the discounted charge.
6. **Transition from Honki Set discount to Loyal** — Lesson month 7 (charge starting 4/28) uses M as basis (5% Loyal = non-Honki discount). This creates yet another O value.
