Case 2 - B2C FLP (15/month, Full Month) → B2B (8/month) Transition Mid-Month, 3 Lessons Taken

[Story]
When a student on a B2C FLP plan (full calendar month contract) transitions to B2B mid-month after taking 3 lessons, all remaining FLP tickets are voided at the B2B start date and a refund is issued. The B2B Charge must appear in the CSV for the B2B start month even if no lessons were taken. FLP plans have no ticket carryover.

How to Verify:
[Precondition] Student [student_id] has the following charges:
order_no,charge_id,type,plan,start_date,end_date,usage_notes
[order_no],[charge_1_id],B2C,FLP 15/month,2026-02-01,2026-02-28,"Charge 1. 3 lessons taken in Feb. B2B starts 2/20 → 12 remaining tickets voided."
[order_no],[charge_2_id],B2B,8/month,2026-02-20,2026-03-19,"Charge 2. B2B new charge. No lessons taken through end of February."
[order_no],[refund_charge_id],Refund,,2026-02-XX or 2026-03-XX,,"Refund executed in Feb or Mar. 12 remaining tickets × ¥990 = ¥11,880 negative."

Note:
FLP ticket validity = contract period (2/1–2/28). No carryover.

[Steps]
Student takes 3 lessons in February before B2B start (Charge 1)
B2B starts 2/20 → 12 remaining FLP tickets voided; refund = 12 × ¥990 = ¥11,880
Refund is executed in February or March (confirm execution month with dev)
Generate the February monthly report (target_ym=202602) via the 202603 batch
Generate the March monthly report (target_ym=202603) via the 202604 batch
Generate the April monthly report (target_ym=202604) via the 202605 batch
