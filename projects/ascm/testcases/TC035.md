# [ASC-301]
[Bizmates][MonthlyCalculation] Some charge_ids are created duplicatedly — Premature Expiry in Lookahead Window

[Story]
If a student is requesting REST and the REST date is next month, tickets should remain valid in the current month and expire in the following month when the contract actually ends. However, the system is expiring tickets one month early (in April instead of May) due to the 2-day lookahead logic firing prematurely for terminal charges (no successor) whose `end_date` falls within 2 days of the current month-end.

```csv
id,コンテンツ,target_ym,student_id,department_id,order_no,charge_id,total,number_of_carried_over_lessons,number_of_lessons_taken,number_of_expired_lessons,number_of_remaining_lessons,paid_price
17018,Bizmates,202605,121073,,,3001753,15,15,0,15,0,14850
```

*Bug: carries over the 15 from April's incorrect expiry and expires again. Double revenue.*

[Root Cause]

The `is_ticket_expiry_month` lookahead condition in the Grouped CTE:

```sql
OR (
    om.end_date > LAST_DAY(om.month_start)
    AND om.end_date <= DATE_ADD(LAST_DAY(om.month_start), INTERVAL 2 DAY)
    AND NOT EXISTS (same-order successor)
)
```

For charge 3001753 in April:
- `end_date (2026-05-02) > LAST_DAY('2026-04-01') (2026-04-30)` = TRUE
- `end_date (2026-05-02) <= DATE_ADD('2026-04-30', INTERVAL 2 DAY) (2026-05-02)` = TRUE
- No successor exists (student requested REST) → NOT EXISTS = TRUE

All conditions TRUE → `is_ticket_expiry_month = 1` → expiry fires in April.

But the business rule says: tickets are valid until `end_date` (May 2nd). April is not the expiry month — May is. The lookahead is firing one month too early for FLP charges that end on day 1-2 of the next month.

[Fix]

Gate the lookahead on `om.rn = om.total_rows` — only fire if this is the LAST row for the charge in the CTE. If a next-month row exists, expiry will fire there via the ticket validity check instead.

```sql
OR (
    om.rn = om.total_rows  -- FIX ASC-301
    AND om.end_date > LAST_DAY(om.month_start)
    AND om.end_date <= DATE_ADD(LAST_DAY(om.month_start), INTERVAL 2 DAY)
    AND NOT EXISTS (same-order successor)
)
```
