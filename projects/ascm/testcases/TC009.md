[ASC-151]
Case 1 - B2C FLP (15/month) → B2B (8/month) Transition Mid-Contract

[Story]
When a student on a B2C FLP plan transitions to B2B mid-contract, remaining FLP tickets are voided at the B2B start date and a refund is issued. The B2B Charge 2 must appear in the CSV for the B2B start month even if no lessons were taken. FLP plans have no ticket carryover — ticket validity equals the contract period only.

How to Verify:
[Precondition] Student [student_id] has the following charges:
order_no,charge_id,type,plan,start_date,end_date,usage_notes
[order_no],[charge_1_id],B2C,FLP 15/month,2026-01-25,2026-02-24,"Charge 1. 3 lessons in Jan, 3 lessons in Feb. B2B starts 2/20 → remaining tickets voided."
[order_no],[charge_2_id],B2B,8/month,2026-02-20,2026-03-19,"Charge 2. B2B new charge. No lessons taken through end of February."
[order_no],[refund_charge_id],Refund,,2026-02-XX,2026-02-XX,"Refund executed in February. 9 remaining tickets × ¥990 = ¥8,910 negative."

Note:
FLP ticket validity = contract period (1/25–2/24). No carryover between months.

[Steps]
Student takes 3 lessons in January (Charge 1)
Student takes 3 lessons in February before B2B start (Charge 1)
B2B starts 2/20 → 9 remaining FLP tickets voided; refund = 9 × ¥990 = ¥8,910
Refund is executed in February
Generate the January monthly report (target_ym=202601) via the 202602 batch
Generate the February monthly report (target_ym=202602) via the 202603 batch
Generate the March monthly report (target_ym=202603) via the 202604 batch
