# [ASC-296]
[Bizmates] B2C Fifteen Lesson Plan Expiration Failure — Tickets Incorrectly Counted as Remaining

[Story]
For Bizmates B2C students on the 15-lesson plan (FLP), tickets are strictly valid only within their specific contract period. However, the system is failing to expire unused tickets at the end of the month boundaries. Instead of flushing them to expired status, it incorrectly marks them as `number_of_remaining_lessons`, which carries them forward and causes under-reporting in both `number_of_expired_lessons` and `paid_price`.

[Precondition]
* **Student ID:** S00000281657 (B2C Student)
* **Plan:** 月15回プラン (15 lesson plan, Base Price: ¥14,850, Unit Price: ¥990 per lesson)
* **Relevant Charge History Sequence:**
* **Charge 3025049:** 2026/04/01 – 2026/04/30 (11 taken, 4 should expire)
* **Charge 3062722:** 2026/05/01 – 2026/05/31 (12 taken, 3 should expire)

[Steps]
1. Run the calculation batch updates generated on 2026-06-11.
2. Inspect the output sheets for the April cycle (`202604`) and May cycle (`202605`).
3. Search for student_id "281657".
