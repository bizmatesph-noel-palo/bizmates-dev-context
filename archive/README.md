# Archive

Superseded documents kept for historical tracing. Nothing here is an active project reference.

## Convention

Files are stored under `archive/` **mirroring their original path**, so the origin is visible at a glance:

```
archive/<original/relative/path>/<filename>
```

Example: a file archived from `docs/foo.md` lives at `archive/docs/foo.md`.

To restore a file, move it back to the same relative path without the `archive/` prefix.
